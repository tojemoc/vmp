Wrong GitHub Pages deployer

You are seeing this page because GitHub’s dynamic pages-build-deployment workflow published the raw /docs folder (markdown and templates). That workflow has no workflow file and must not be re-run to refresh SideStore / nightly.link links.

To restore the install site (AltStore source + nightly.link downloads):

  1. Open Actions → Publish SideStore Pages
  2. Run workflow from main (leave run ID empty to use the latest Mobile artifacts build).

Or run Mobile artifacts from main with publish_release enabled (full rebuild).
